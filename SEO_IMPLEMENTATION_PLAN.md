# FareTransit SEO Implementation Plan

This branch implements SEO in phased, quality-controlled steps. The goal is to improve crawlability, indexation, page quality, internal linking, structured data, performance, and measurement without generating thin or doorway pages.

## Phase 1 — Technical SEO foundation
- Central SEO registry for indexable pages
- Canonical and robots policy
- Structured data helpers
- Automatic sitemap generation
- Stronger robots.txt rules
- Explicit noindex policy for transactional/private routes
- SEO test coverage

## Phase 2 — Indexable content architecture
- /flights hub
- /airlines hub and selected airline guides
- /baggage hub and selected baggage guides
- /fare-types hub and selected fare guides
- /guides hub
- /about, /how-it-works, /editorial-policy
- Internal related-content links and breadcrumbs

## Phase 3 — Route quality
- Upgrade existing route pages with useful non-template sections
- Add route quality gate before sitemap/indexing
- Add reviewedAt/source metadata and related links

## Phase 4 — Measurement
- GA4 organic-funnel events
- Search Console setup checklist
- Conversion/key-event map

## Phase 5 — Ongoing authority
- Original travel-data research and digital PR
- Content refresh/pruning workflow

Off-site backlinks and rankings cannot be guaranteed or safely automated in code. This repository covers the site-side SEO system and measurement needed to support long-term ranking growth.
