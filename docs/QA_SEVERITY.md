# QA Severity

- **P0** — security, payment, privacy or data-integrity catastrophe. Stop/revert immediately.
- **P1** — core booking, authorization, ticketing, merchant-demo isolation or admin workflow unusable. Block release.
- **P2** — important feature partially broken or incorrect. Fix before normal release unless explicitly accepted.
- **P3** — meaningful UI/UX inconsistency with workaround. Schedule based on impact.
- **P4** — cosmetic cleanup with no workflow impact.
