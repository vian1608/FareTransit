# Independent ticket delivery activity
Add migration 133 before deploying. No existing booking/payment/dispatch state changes.
New HTML e-tickets contain a plain-language open tracking notice and a recipient-specific image at the public /api/independent-ticket-open/<opaque uuid>.gif endpoint. It stores only delivery id, event kind, source and UTC timestamp; duplicate image fetches in a minute collapse into one event. No IP or user agent is stored by application code. Old snapshots without the notice are sent as archived, without a pixel. Original PDFs remain unchanged. Opens are not proof of a person reading or downloading a PDF.
Optional Resend provider event endpoint: https://www.faretransit.com/api/webhooks/resend-independent-tickets. Configure Resend events email.sent, email.delivered, email.delivery_delayed, email.bounced, email.failed, email.complained, email.suppressed and optionally email.opened. Put the signing secret in production Vercel environment RESEND_INDEPENDENT_TICKET_WEBHOOK_SECRET, redeploy and verify with Resend dashboard. Do not enable domain-wide open tracking unless explicitly desired; first-party open detection is scoped to tickets. Native events use verified Svix raw-body signature and event-id deduplication. No customer mail must be sent for deployment verification.
